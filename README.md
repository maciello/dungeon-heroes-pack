# Dungeon Heroes (RPG Series)

A Minecraft 1.21.1 Fabric RPG modpack (classes, spells, bosses, dungeons). It updates itself every time you start the game.

## What you need

- **PolyMC** launcher with your Microsoft account added.
- **Java 21.** In PolyMC: *Settings → Java → Auto-detect*. If nothing shows up, install Java 21 (for example Eclipse Temurin 21) and auto-detect again.
- **16 GB RAM** in your PC is best. The pack gives the game 8 GB.
- **The server address and an invite** from the host (ask them).

## Install (one time)

1. In PolyMC, click **Add Instance → Import from zip**.
2. Paste this link and click **OK**:
   ```
   https://github.com/maciello/dungeon-heroes-pack/releases/download/instance/DungeonHeroes-main.zip
   ```
3. Select **Dungeon Heroes** and click **Launch**.
4. A window called *Updating modpack* downloads about 1100 files. The first time takes a few minutes. Wait for it.
5. If it asks to update the Minecraft or Fabric version, click **Yes**. Then launch again.
6. In the game: **Multiplayer → Add Server**, enter the address from the host, and join.

## Updates

You do nothing. Every launch checks for a new pack version and downloads only what changed.

If the server kicks you with a mod mismatch, close the game and launch again.

## Problems

| problem | fix |
|---|---|
| Java error at start | *Edit Instance → Settings → Java*: pick Java 21. |
| Game crashes, "out of memory" | *Edit Instance → Settings → Java*: set maximum memory to 8192 MB or more. |
| Download failed | Launch again. It continues where it stopped. |
| A window asks you to download a file by hand | Tell the host. Do not download mods from other sites. |

## Good to know

- Your own settings (keys, video, sound) are yours. Updates never change them.
- Mod settings that come with the pack can reset when the pack updates.
- Do not add or remove mods in this instance. Your game must match the server. Ask the host instead.
- The pack version shows in the *Updating modpack* window. All versions are listed under [Tags](https://github.com/maciello/dungeon-heroes-pack/tags).
